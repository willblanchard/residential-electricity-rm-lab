## Iteration 0 ASI

The highest-leverage first move is to remove stale "placeholder" language and make the artifact status explicit: this is now a stylized, source-backed case-study model with static NLR/OEDI inputs, static WattShift rate outputs, and current interactive scenario exports. That single credibility cleanup should touch the footer and any nearby source/status copy without changing the model mechanics.

## Iteration 1 ASI

The next highest-leverage move is to sharpen the opening decision frame: make it explicit that the dashboard compares the rate design a utility can defend as revenue-neutral in a PUC filing against realized economics after elastic behavior, thermostats, and batteries respond. Do this in the hero lead and the three-step story cards without adding a new section or changing chart mechanics.

## Iteration 2 ASI

The last high-leverage polish pass should make the population economics map self-explaining at the moment of use. Add a compact reading guide near the map controls that defines the top bar, bottom stacked bar, row labels, and click behavior; keep it visually quiet and avoid expanding the page with a new large section.

## Final Notes

Stable wins:
- The revenue-neutral filing frame is now explicit in the hero and story cards.
- The model status no longer calls the scenario outputs placeholders.
- The population economics map now has a local reading guide, while raw values remain collapsed for audit.
