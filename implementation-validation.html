A browser model makes the LP results auditable.

The implementation converts the optimization setup into a static site with transparent inputs, interactive controls, sanity checks, and CSV exports. That lets the presentation show not only the recommendation, but also how the result changes under different rate and adoption assumptions.

Data foundation

The report's source portfolio starts with 100 simulated residential homes from the ResStock / NLR end-use load profile data. Each home has 15-minute electricity consumption for a full year, which supports both annual-demand WTP calibration and coincident-peak capacity analysis.

100 homes The source data represents a small but diverse Illinois residential portfolio.
35,040 intervals / home Fifteen-minute observations over one calendar year produce each building load profile.
3.5M observations The full sample supports peak-period reconstruction before the browser site normalizes results for presentation.

Validation checks

The implementation is checked against core economic expectations: a no-signal TOU case should match flat pricing, demand charge at zero should collapse to the fixed-rate baseline, and responsive devices should reduce bills only when the dispatch actually helps the customer under the tariff.

Rate sanity Flat-equivalent cases are tested before interpreting model outcomes.
Device economics Thermostat and battery response are evaluated against actual bill impact.
