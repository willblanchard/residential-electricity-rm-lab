A browser model makes the LP results auditable.

The implementation converts the optimization setup into a static site with transparent inputs, interactive controls, sanity checks, and CSV exports. That lets the presentation show not only the recommendation, but also how the result changes under different rate and adoption assumptions.

Validation checks

The implementation is checked against core economic expectations: a no-signal TOU case should match flat pricing, demand charge at zero should collapse to the fixed-rate baseline, and responsive devices should reduce bills only when the dispatch actually helps the customer under the tariff.
