Demand response from Nathan's curves

For each building b, the MATLAB WTP curve converts an effective electricity price into annual demand. The dashboard keeps the raw curve visible on the WTP page and uses bounded response in the presentation economics. 

effective_price_bh(t) =
  energy_price_h(t) + demand_charge_t * peak_b(t) * 12 / annual_kwh_b

demand_bh(t) = shape_bh * max(0, (intercept_b - effective_price_bh(t)) / (slope_b / 2.106))

Objective

Choose the tariff that maximizes realized monthly gross margin after customer response. 

max sum_t z_t * Margin_t

where
  Margin_t = Revenue_t - EnergyCost_t - CapacityCost_t
  Revenue_t = sum_b sum_h bill_revenue_bh(t)
  EnergyCost_t = sum_b sum_h wholesale_cost_h * demand_bh(t)
  CapacityCost_t = capacity_cost_per_kw_month * P_t

Core constraints

sum_t z_t = 1

sum_t z_t * Revenue_t >= 0.95 * Revenue_flat

-0.005 * Revenue_flat <=
  sum_t z_t * (FiledRevenue_t - Revenue_flat)
<= 0.005 * Revenue_flat

sum_t z_t * P_t <= Capacity

z_t >= 0 for all t
z_t in {0, 1} for one selected filed tariff

The dashboard enumerates the binary choices directly, so the on-page optimizer and CSV are the solved candidate table for this LP.

Tariff expansion

Flat:
  t = p_k

TOU:
  t = (p_off, p_mid, p_peak)
  p_peak >= p_mid >= p_off
  p_peak / p_off in [1, 5]

Demand charge:
  t = (p_energy, dc_j)
  dc_j in [$0, $30]/kW-month

Peak linearization

P_t >= sum_b demand_bh(t)
  for every hour h in the peak window

P_t <= Capacity

This is the same capacity logic used in Nathan's capacity file: 68 kWh per 15 minutes, converted to kW.

Formulation logic

For each candidate tariff, the model calculates customer bills, adjusted usage, energy cost, capacity cost, revenue, and margin. Candidates are ranked by gross margin after checking the filing baseline and peak screen.

Revenue Monthly customer bills under the chosen tariff and response scenario.
Cost Wholesale-energy exposure plus a peak-capacity proxy.
Margin The utility-side economic objective used to compare tariffs.
